# @rightandabove/auth-oidc-core

Shared contracts for the auth-oidc stack: route prefix, HTTP paths, Zod schemas, DTOs, and event names. Depends only on `zod`.

**Install:** `npm i @rightandabove/auth-oidc-core`

Used by [`@rightandabove/auth-oidc-nest`](https://www.npmjs.com/package/@rightandabove/auth-oidc-nest) and [`@rightandabove/auth-oidc-react`](https://www.npmjs.com/package/@rightandabove/auth-oidc-react).

## Sibling packages

| Package | Role |
| --- | --- |
| `@rightandabove/auth-oidc-core` | This package — schemas & shared types |
